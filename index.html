Frequently Asked Questions (FAQ)

Apa itu HTML dan mengapa itu penting?

HTML (HyperText Markup Language) adalah bahasa markup yang digunakan untuk menyusun struktur halaman website. HTML penting karena menjadi dasar untuk menampilkan berbagai elemen, seperti teks, gambar, tautan, dan formulir pada halaman web.

Bagaimana cara menghubungkan CSS ke HTML?

CSS dapat dihubungkan ke HTML menggunakan tag link yang diletakkan di dalam elemen head. Contohnya: link rel="stylesheet" href="style.css". Atribut href menunjukkan lokasi file CSS yang digunakan untuk mengatur tampilan halaman website.

Apa fungsi utama JavaScript?

JavaScript memberikan interaktif pada halaman web, seperti validasi, galeri gambar dinamis, dan pembaruan konten.

Mengapa desain responsif itu krusial?

Desain responsif penting agar tampilan website dapat menyesuaikan berbagai ukuran layar, mulai dari komputer hingga smartphone. Dengan desain responsif, pengguna dapat membaca dan berinteraksi dengan konten secara nyaman di berbagai perangkat.

Apa perbedaan antara Flexbox dan CSS Grid?

Flexbox digunakan untuk mengatur tata letak elemen dalam satu dimensi, yaitu baris atau kolom. Sementara itu, CSS Grid memungkinkan pengaturan elemen dalam dua dimensi sekaligus, yaitu baris dan kolom, sehingga cocok untuk tata letak yang lebih kompleks.

Kapan sebaiknya menggunkan framework CSS?

Framework CSS cocok digunakan ketika ingin membangun website dengan lebih cepat dan konsisten. Framework menyediakan komponen serta aturan gaya siap pakai yang dapat disesuaikan dengan kebutuhan proyek.

Bagaimana cara kerja caching browser?

Caching browser bekerja dengan menyimpan salinan file website, seperti gambar, CSS, dan JavaScript, di perangkat pengguna. Ketika website dikunjungi kembali, browser dapat menggunakan file yang tersimpan sehingga waktu pemuatan halaman menjadi lebih cepat.

Apa perbedaan GET dan POST request?

GET digunakan untuk meminta atau mengambil data dari server, sedangkan POST digunakan untuk mengirim data ke server. GET biasanya menampilkan parameter pada URL, sementara data POST umumnya dikirim melalui bagian isi permintaan (request body).

Apa kegunaan utama dari SQL database?

SQL (Structured Query Language) digunakan untuk mengelola data dalam database relasional. Dengan SQL, pengguna dapat menambahkan, mengambil, memperbarui, dan menghapus data sesuai kebutuhan aplikasi.
